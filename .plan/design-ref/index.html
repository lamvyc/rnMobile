关于称平安 v1.0.0

设计系统变更对照

close原版问题

  • • Emoji 图标（✅🔥📅🏆🛡️）
  • • 配色单一（全站 #10B981）
  • • 背景纯白，无层次感
  • • Tab 图标用文字符号
  • • 字体层级不足
  • • Shadow 过轻，整体"飘"

check新版改进

  • • Material Icons Round 全套图标
  • • 多色系（主色/强调/中性）
  • • 暖白背景 + 渐变层次
  • • 统一 Tab Icon 规范
  • • 完整排版层级系统
  • • 彩色 Shadow + 质感卡片

build落地到 RN 需要的改动

1. 安装 @expo/vector-icons（已内置 Expo，可直接 import Ionicons / MaterialIcons）
2. 替换所有 Emoji 为 <MaterialIcons name="..." />
3. 更新颜色常量文件，定义完整色阶
4. 调整 Shadow 参数（shadowColor 加入主题色）
